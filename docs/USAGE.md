# 使用 SK Matrix

1. 打开 sk-matrix-0.1.0-win-x64.exe。
2. 点击「＋ 添加账号」，展开账号页面，登录并选择课程。
3. 每个账号分别完成登录和选课，再单独开始或点击「全部开始」。
4. 返回拼盘直接看实际视频画面。需要更大画面时展开对应账号。
5. 顶部可切换「画面优先 / 概览布局」；每行支持 2、3、4 列。
6. 「共享 API」保存一次提供商、模型和密钥。所有账号共用配置。
7. 「一键后台」最小化窗口；从任务栏恢复。关闭窗口会退出。
8. 停止后会终止旧页面执行链并暂停视频。重开软件保留账号资料，
   任务保持停止状态。

## 账号和数据

数据保存在 %APPDATA%/io.climate13.skmatrix/manager：

- config.toml：共享设置。
- accounts.json：账号备注和页面地址。
- accounts/<编号>/webview：各账号独立的浏览器登录资料。

SK Matrix 使用新的应用标识。此前 uXueScript 改版的数据不会自动搬入；
首次使用需要分别登录。移除账号卡片会停止任务并保留本机资料，
新账号使用新的编号。

API Key 沿用本地 TOML 保存方式；不要公开配置文件、浏览器资料和日志。
项目源码包及 GitHub 工作流不包含实际用户资料。

## 后台的边界

后台参数和有效 WebView 尺寸用于减少最小化/遮挡导致的中断；
任务启用时会申请防自动休眠。手动休眠、关机、断网、登录过期、
平台验证或系统强制终止仍可能中断处理。

媒体时间是本地播放器时间，课程完成情况以平台记录为准。
账号数量没有固定的槽位上限，但同时运行数量受硬件和平台限制。
视频播放无需模型 API；共享 API 的额度和费用由你的提供商决定。

## 页面卡住时恢复（0.1.1）

- 账号卡片点击“↻ 重载”，或展开后点击“重新加载”。重载当前页面，复用同一个账号 WebView 与登录资料，不清理 Cookie。正在运行的任务会按原运行状态重新加载。
- 点击“返回选课”可回到平台个人首页，并停止该账号当前任务。
- 页面黑屏、鼠标焦点在课程页时，使用窗口顶部原生“页面恢复”菜单：“返回账号拼盘”退出展开页；“重新加载展开的账号”重载当前账号。返回拼盘不停止其他账号。
- 平台会话已过期、平台主动登出时，仍需重新登录；恢复操作不会延长平台登录有效期。

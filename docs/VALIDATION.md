## 0.1.1 页面恢复

前端类型检查、生产构建通过。前端共 88 项测试通过（其中新增 3 项账号恢复交互测试）；Rust 工作区 52 项通过、11 项依原设置跳过。构建配置测试需本机 Rust 工具链环境；初次缺少环境的运行失败，补齐路径后 4 项全部通过。

新增原生菜单的操作由 Rust 直接执行，不依赖课程页 JavaScript。重载复用同一 WebView，不重建账号 ID、不清理 Cookie、不改变应用标识或数据目录。实际平台会话过期仍需重新登录。

Windows 原生窗口验收：在本地测试页模拟账号黑屏后，通过“页面恢复→重新加载展开的账号”恢复画面，测试页确认 localStorage 与 Cookie 均保留；通过“返回账号拼盘”恢复总览，两个账号仍在；第二账号独立重载后也保留各自存储。未使用真实课程或真实账号测试。课程页可能拦截快捷键，因此最终发布只展示已验证的按钮和原生菜单。
